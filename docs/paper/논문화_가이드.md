## 1. 한 문장 기여 (실험으로 역검증 완료 – 검증 과정에서 주장 범위를 좁힘)

> **바람장에서 SOC를 최소화하는 드론 배송 경로계획에서, 장애물 궤적 예측의 불확실성을 '예측 시간에 따라 커지는 기회 제약 튜브'로 표현하면 SIPP 안전구간을 해석적으로 계산할 수 있다. 예측 오차가 가우시안에 가까우면 이 튜브는 고정 최악 버퍼와 같은 실측 안전성을 4.9 % 적은 에너지로 얻는다. 그러나 오차 꼬리가 두꺼우면 이 이득이 사라진다. 따라서 '얼마나 부풀릴지(ε)'뿐 아니라 '시간에 따라 어떤 모양으로 부풀릴지'를 오차 분포의 꼬리에 맞춰 정해야 한다.
> 실측 ADS-B 항적(저고도 18대)에서 예측 오차는 실제로 꼬리가 두껍고(99.9 % 분위수 9.1σ) τ^1.5로 커진다. 데이터로 맞춘 구간별 선형 모양은 시점별 위험 보정을 회복한다. 그러나 재관측이 잦은 폐루프에서는 회피 불가 조우와 반응 시간 여유가 안전·에너지를 좌우한다.**

처음 기여 문장은 "고정 버퍼와 같은 안전성에 에너지 4.9 % 절감"이었습니다. 그런데 역검증 중 Student-t 오차(꼬리가 두꺼움)로 시험하자 이 우위가 사라졌습니다(§3.4). 그래서 주장에 조건을 붙이고, 그 이유(오차 꼬리에 따른 최적 팽창 반경의 모양)를 두 번째 기여로 삼았습니다. 심사에서 지적받기 전에 스스로 찾아 보고하는 편이 논문 신뢰도에 유리합니다.

## 2. 학술적 의미 (왜 논문이 되는가)

### 2.1 이론·알고리즘 측면
1. **바람장에서는 에너지 비용 노름이 볼록하지 않다는 것을 정량화했습니다.**
   - Theta*/Lazy Theta*는 "직선이 보이면 직결"을 채택합니다. 이 규칙은 거리 비용의 삼각부등식에 근거합니다.
   - 같은 고도에서 바람이 균일하다고 가정해도, 실제 기체 전력모델과 실제 바람으로 그린 비용 노름의 단위구는 볼록 껍질에서 **1.1~9.0 %** 안쪽으로 들어갑니다(E7). 즉 바람 속 에너지 최적화에는 "지름길을 에너지로 비교하는 규칙"이 원리적으로 필요합니다.
   - 문헌 [gu2026wind]의 wind-aware Theta*가 이 점을 어떻게 다뤘는지는 초록으로 확인되지 않습니다. 원문 확인이 필요합니다 [확인요망].
2. **시간 증가 기회 제약 튜브의 안전구간을 해석해(closed form)로 구했습니다.**
   - 이동 장애물 + 선형 증가 불확실성은 셀마다 2차 부등식이 되며, **선행계수의 부호가 바뀔 수 있습니다.** 불확실성 증가가 장애물 속도보다 빠르면 위험구간이 **두 개로 갈라집니다.**
   - 표본(샘플링) 없이 정확한 안전구간표를 만들 수 있어 SIPP와 바로 결합됩니다. 이동 장애물 + 불확실성 + any-angle SIPP + 에너지 비용의 조합은 확인한 문헌 범위에서는 보지 못했습니다 [확인요망: 2024~2026 추가 조사].
3. **'팽창 반경의 모양'이 오차 꼬리에 따라 달라야 함을 보였습니다.**
   - 기존 기회 제약 계획은 대부분 가우시안을 가정하고 위험 한도 ε만 조절합니다.
   - 본 연구의 위험–에너지 곡선(F19)을 보면, 가우시안에서는 시간 증가 튜브(반경 ∝ σ(τ))가 가장 효율적입니다. 꼬리가 두꺼우면(Student-t) 고정 버퍼가 같거나 더 좋습니다.
   - 1차 해석: 조우마다 반경 r_i를 나눠 쓰는 문제로 보면, 최적 반경은 가우시안에서 r ∝ σ(로그 보정)이고 거듭제곱 꼬리 u^(−α)에서 r ∝ σ^(α/(α+1))입니다(α=3이면 σ^0.75). 꼬리가 두꺼울수록 '완만한' 모양이 최적이 되어 고정 버퍼 쪽으로 이동합니다.
   - 실무 함의: 실제 항적 데이터로 예측 오차의 꼬리를 추정해 팽창 모양을 정해야 합니다. τ에 대해 구간별 선형인 모양이면 해석해 안전구간을 그대로 쓸 수 있습니다.
4. **장거리 그래프 탐색에 기회 제약을 넣었습니다.**
   - 기존 기회 제약 계획 [blackmore2011chance, dutoit2012robot, zhu2019chance]은 주로 연속 최적화나 MPC이고, 짧은 지평에서 동작합니다.
   - 본 연구는 수 km, 수 분 규모의 임무 전체를 에너지 목적함수로 탐색하면서 위험을 제한합니다.

### 2.2 실증 측면 (실제 데이터)
- **실측 기반 모델**: 실제 지형(Copernicus DSM), 건물(Overture 7,109동), 운영 예보 바람(GFS 고도별·시간별)을 썼고, 실측 비행 198회로 보정·검증한 전력모델(R² 0.77)을 사용했습니다.
- **에너지 절감의 출처를 분해했습니다**(가정 축소 실험): 구간 속도 최적화(+10~13 %p) > 에너지 지름길(+4.1 %p) > 고도 선택(+2.8~3.1 %p) ≫ 시간가변 바람·질량(≤0.3 %p, 1회 비행 기준). 후속 연구가 어디에 투자해야 하는지 알려주는 결과입니다.
- **위험–에너지 절충 곡선을 두 오차 모델에서 정량화했습니다**(시나리오 30개 × 샘플 1,000개, 방법 15종). 가우시안에서 고정 버퍼 대비 이득은 통계적으로 유의했고, 꼬리가 두꺼운 오차에서는 이득이 사라졌습니다. 이 '부정적 결과'도 함께 보고합니다.

- **실측 ADS-B 항적으로 예측 오차를 직접 측정했습니다**(OpenSky, `traffic` 패키지 샘플). 가우시안 가정이 모양(선형 증가)과 꼬리 모두에서 틀린다는 것을 보였습니다. 데이터로 맞춘 팽창 모양이 학습에 쓰지 않은 기체에서도 보정된다는 것도 확인했습니다.
- **실측 궤적 폐루프 시험의 '부정적 결과'도 기여입니다.** 시점별 보정이 폐루프 안전성으로 이어지지 않았고, 빠른 유인기는 수평 회피로 막을 수 없었습니다. 이 결과는 감시 주기·탐지 시각·고도 분리 설계의 필요성을 정량적으로 보여 줍니다.

### 2.3 실무 측면
- **위험 한도 ε가 직관적인 조절 손잡이가 됩니다.** 단, 실측 위험이 ε보다 훨씬 작으므로(보수적) ε를 그대로 임무 위험으로 읽으면 안 됩니다. 정직하게 보고할 점입니다.
- **폐루프에서는 계획 안정성(재계획 감소)이 주된 이득입니다.** UTM 환경에서 의미가 있을 수 있습니다 [인용필요].

## 3. 핵심 결과 요약 (논문 표·그림과 대응)

날짜를 나눠 검증한 결과 R² 0.77, MAPE 9.6 %입니다. 거리 비례 모델은 R² −1.47로 최단경로 비용 가정이 부적절함을 보여줍니다.

### 3.2 계획 요소별 기여 (Table 2, Fig. F5, F11, F13)
- 강풍(15시) 배송에서 SOC 소모는 기존 방식 102.9 %p, WE-LT* 76.7 %p입니다.
- 비볼록 노름: 1.1~9.0 %.

### 3.4 모델 불일치 (Student-t, 자유도 3)
그림 F19와 원고 Table 3b에 해당합니다. 계획은 가우시안을 가정하고, 실제 오차만 Student-t(자유도 3, 같은 표준편차)로 바꿔 평가했습니다. 모든 방법이 실행 가능한 29개 시나리오 기준입니다.

| 방법 | ε | 에너지 증가 | 가우시안 충돌률 | Student-t 충돌률 |
|---|---|---|---|---|
| 튜브 | 0.05 | +11.9 % | 0 | 0.53 % |
| 튜브 | 0.01 | +15.1 % | 0 | 0.28 % |
| 튜브 | 0.001 | +19.3 % | 0 | 0.17 % |
| 튜브 | 10⁻⁴ | +22.7 % | 0 | 0.12 % |
| 혼합 튜브 (λ=0.5) | 0.01 | +19.0 % | 0 | 0.15 % |
| 혼합 튜브 (λ=0.5) | 0.001 | +24.1 % | 0 | 0.086 % |
| 고정 버퍼 | 0.2 | +12.0 % | 0.028 % | 0.40 % |
| 고정 버퍼 | 0.05 | +17.6 % | 0 | 0.18 % |
| 고정 버퍼 | 0.01 | +22.2 % | 0 | 0.069 % |

- **같은 에너지 기준**: 튜브(ε=0.01)는 고정 버퍼(ε=0.05)보다 에너지가 2.2 % 적지만(p = 0.006), 충돌률은 0.28 % vs 0.18 %로 더 높습니다.
- **같은 위험 기준**: 튜브(ε=0.001, 0.17 %)와 고정 버퍼(0.18 %)의 에너지 차이는 +1.2 % [−0.5, 3.1], p = 0.27로 유의하지 않습니다.
- **가장 낮은 위험 영역**: 고정 버퍼가 더 좋습니다(0.069 % @ +22.2 % vs 튜브 0.12 % @ +22.7 %).
- **혼합 튜브**: 두 방법 사이에 위치하며, 꼬리가 두꺼울 때 고정 버퍼를 앞서지 못했습니다.
- **대기 시간**: 강건 계획은 공간뿐 아니라 시간도 씁니다. 비행당 호버 시간은 공칭 0.6 s, 튜브(ε=0.05) 7.5 s, 고정 버퍼 10.5 s(이륙 지연 평균 1.0 s 추가)이고, 비행 시간은 132 → 145 → 152 s입니다. 계획된 대기를 지키지 않고 같은 경로를 날면 조우 시각이 10~12 s 어긋나 위험 평가가 무효가 됩니다.

### 3.5 폐루프 (Table 4, Fig. F16c, F15)
- 20 s 재관측에서 충돌은 2/600 vs 0/600으로 **유의하지 않습니다**. 재계획은 비행당 0.32 → 0.087회(−73 %, p = 0.002), 에너지는 +2.6 %입니다.
- 변경 발표 기반(E9): 이벤트 방식 2회 재계획 = 30 s 주기 5회와 같은 안전성이고, 60 s 주기는 충돌합니다.

  - 회피 가능한 382회에서 충돌은 공칭 7회, 팽창한 방법 2~4회였습니다(유의하지 않음).
  - 최소 이격 중앙값은 45 m → 107~184 m로 늘었습니다.
  - 데이터 튜브는 가우시안 튜브보다 에너지가 +2.1 %(p = 3×10⁻¹⁸) 더 들었습니다. 반응 시간 하한을 넣자 −0.6 % 줄었고, ε=0.01에서는 가우시안과 같았습니다.
- **원래 속도(50 m/s)의 유인기:** 95~100 % 조우에서 완화가 필요했습니다. 수평 회피로는 확률 보장이 불가능합니다.
